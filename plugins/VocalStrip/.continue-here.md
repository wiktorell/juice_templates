## Context to Preserve

**Key Architectural Decisions:**
- Bus layout: mono input (AudioChannelSet::mono()) + stereo output (AudioChannelSet::stereo())
- Signal flow: EQ (mono) -> Comp (mono) -> mono-to-stereo -> Delay (mono on ch0) -> Reverb (stereo)
- Delay-to-Reverb send: pre-D/W tap from delay wet signal, independent of delay_mix
- Compressor: juce::dsp::Compressor + Simple mode formula (threshold=-6-(amount*34), ratio=2+(amount*8))
- Reverb: juce::dsp::Reverb with Plate/Room parameter mapping (not two separate algorithms)
- GR meter: std::atomic<float> grMeterValue (audio thread write, 30 Hz UI timer read)
- Bypass: block-level (not sample-accurate) for all 4 sections
- juce_dsp module required (IIR filters, Compressor, DelayLine, Reverb, DryWetMixer)
- CRITICAL: juce::dsp::Reverb must use prepare(spec) + process(context) (pattern #17)
- CRITICAL: Bus config in constructor, not prepareToPlay

**DSP-1 Implementation Details:**
- EQ filters: 4 separate juce::dsp::IIR::Filter<float> instances (not ProcessorChain)
- Coefficient update uses *filter.coefficients = *Coefficients::make*() (deref assignment)
- Compressor processes mono AudioBlock via getSingleChannelBlock(0)
- GR computed from RMS ratio, makeup gain excluded for accurate reading
- currentSampleRate cached as member for coefficient recalculation

**DSP-2 Implementation Details:**
- DelayLine max size: 200000 samples (constructor arg), prepared with mono spec
- DryWetMixer: linear mixing rule, mono spec
- Feedback: feedbackSample float member, reset to 0 in prepareToPlay
- reverbSendBuffer: mono AudioBuffer, sized to samplesPerBlock in prepareToPlay
- BPM sync: getPlayHead() -> getPosition() -> getBpm() with Optional checks
- After delay D/W mix, ch0 copied to ch1 for stereo output
- Delay processes on ch0 only (mono delay), result mirrored to ch1

**DSP-3 Implementation Details:**
- preDelayL/preDelayR: DelayLine<float, Linear> with 20000 sample max buffer (constructor arg), prepared with monoSpec (1 channel each)
- Reverb: juce::dsp::Reverb prepared with stereoSpec (2 channels) — NEVER juce::Reverb or processMono/processStereo
- reverbDryWet: DryWetMixer<float> prepared with stereoSpec, linear mixing rule
- Pre-delay clamp: juce::jlimit(0.0f, 19999.0f, preDelaySamples) for safe DelayLine access
- reverb.setParameters() called per block with computed Plate/Room params
- Reverb D/W: pushDrySamples(stereoBlock) before reverb, mixWetSamples(stereoOutBlock) after
- reverbSendBuffer added to both ch0+ch1 (mono-to-stereo send) before pre-delay
- reverb_bypass: entire reverb block skipped when true; stereo delay output passes through
